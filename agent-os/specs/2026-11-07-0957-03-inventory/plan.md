### Standards proposals carried (proposal text only; the orchestrator decides)

- S17 (from the lead, supersedes my spec 02 S14 escape wording): every file an agent writes gets a byte-level non-ASCII check (`rg -n '[^\x00-\x7F]'`, with a positive control); Java test data that needs a non-ASCII character is built from code points (`Character.toString(0x2003)`), never from a typed escape, because the editing tools decode a typed backslash-u sequence into the character.
- S18: every hook of a shared test base (cleaning, recorder reset, toggles) has a guard test that fails when the hook is removed (a `PER_CLASS` subclass dirties the state in `@BeforeAll` and asserts it clean in its test).
- S19: every transactional claim (after commit, rollback, atomicity across aggregates) is proven by a failure device in an integration test plus a must-fail probe that removes the `@Transactional` boundary; inspection alone only where no device is possible.
- S20: a rule copied into several layers (a threshold in the domain, the DTO, a query and a view) is pinned at each layer with boundary rows at limit - 1, limit and limit + 1 on a default and a non-default parameter; a figure that production only ever holds at its default (reserved 0, level 3, quantity 10) gets a non-default test value wherever it passes through.
- S21: test event listeners record only (no assertions inside listeners, thread-safe lists), are reset by the shared base hook, keep `fallbackExecution` false, and a rollback device is a `BEFORE_COMMIT` thrower proven non-vacuous by an `AFTER_ROLLBACK` recorder.
