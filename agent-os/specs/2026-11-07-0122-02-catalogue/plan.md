## Contract shared by T3, T5, T6 and T8: ProblemDetail catalogue

`detail` is the exception message (plain English; tests assert it is present, not its wording). `details` is always present, an empty list when there is nothing to list. Content type `application/problem+json`. `title` is the exception title.

| status | code | title | source | details |
|---|---|---|---|---|
| 400 | `validation-failed` | Validation failed | `CommandExceptionHandler` for `MethodArgumentNotValidException` | `[{field, message}]` per field error, sorted by field then message |
| 404 | `book-not-found` | Book not found | `BookDataService.BookNotFoundException` | `[]` |
| 409 | `isbn-already-exists` | ISBN already in catalogue | `BookDataService.IsbnAlreadyExistsException` | `[]` |
| 409 | `book-discontinued` | Book discontinued | `BookDiscontinuedException` translated to `ConflictException` | `[]` |
| 422 | `invalid-isbn` | Invalid ISBN | `InvalidIsbnException` | `[{field: "isbn", message}]` |
| 422 | `unknown-genre` | Unknown genre | `UnknownGenreException` | `[{genre: "FICTION"}, ..., {genre: "POETRY"}]` (ten entries, enum order) |
| 422 | `price-out-of-range` | Price out of range | `PriceOutOfRangeException`, `InvalidMoneyException` | `[{field: "price", message}]` |
| 422 | `invalid-title` | Invalid title | `InvalidTitleException` | `[{field: "title", message}]` |
| 422 | `invalid-author-name` | Invalid author name | `InvalidAuthorNameException` | `[{field: "authors", message}]` |
| 422 | `author-count-out-of-range` | Number of authors out of range | `AuthorCountOutOfRangeException` | `[{field: "authors", message}]` |
| 422 | `publication-year-out-of-range` | Publication year out of range | `PublicationYearOutOfRangeException` | `[{field: "publicationYear", message}]` |
| 503 | from the exception | from the exception | `UnavailableException` (nothing throws it in spec 02; both handlers map it) | from the exception |

Per endpoint: add gives 202, 400, 409 `isbn-already-exists`, the seven 422 codes; change-price gives 202, 400, 404, 409 `book-discontinued`, 422 `price-out-of-range`; discontinue gives 202, 404; search gives 200, 422 `unknown-genre`; get gives 200, 404. Accepted defaults (not in the spec): a concurrent update ends as HTTP 500 (`ObjectOptimisticLockingFailureException` is not mapped); malformed JSON, wrong JSON types and bad UUIDs give Boot's empty-body 400.
