# Standards: Spec 08 Bookstore assistant

- `docs/spec-pack/specs/08-bookstore-assistant.md` decides what. `docs/spec-pack/product/tech-stack.md` and `docs/spec-pack/orchestrator/decisions.md` win over everything else (Spring Boot 4.1.2, Spring AI 2.0.2 through the BOM already imported in the root `pom.xml`, `spring-ai-starter-model-anthropic` without a version, property names without `.options`, the key is `BOOKSTORE_AI_API_KEY`).
- `agent-os/standards/architecture.md`, a pointer to `docs/spec-pack/product/architecture-standard.md`: section 2 rule 7 (Spring AI only in `assistant`), rule 8 (`@RestController` only in `command`, `query`, `assistant`), section 3 naming (`assistant` classes end with `Commands`, `Tools`, `Config`, `Properties`, `Payload`, `View`, `ExceptionHandler`, `RateLimiter` or `ChatModel`; records are top-level), section 4 (inbound adapters call flows only; errors become RFC 9457 `ProblemDetail` through a `@RestControllerAdvice` per adapter package with `code` and `details`; bean validation failures are 400 `validation-failed` with `details [{field, message}]`) and section 5 (web slice tests for `assistant`, end-to-end tests on PostgreSQL via Testcontainers, ArchUnit).
- Skills: bookstore code is written through `.claude/skills/hexagonal-slice` (with `clean-hexagonal-onion`, `ddd-building-blocks`, `layer-testing`). The standard and the spec win over the skills.
- Repo rules from `CLAUDE.md`: referee `./mvnw clean verify` green, budget 60 s; never skip, disable, delete or weaken a test or an ArchUnit rule; never add `ignoreDependency`; never `--no-verify`; never force-push; plain English without em dashes; product files ASCII only; never set, read or write `ANTHROPIC_API_KEY`; never commit a key; no test calls a real LLM; product code never references `docs/spec-pack`, `agent-os`, `.claude` or `CLAUDE.md`.
