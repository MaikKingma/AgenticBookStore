# Standards: Spec 06 Distributor anti-corruption layer

- `docs/spec-pack/specs/06-distributor-acl.md` decides what. `docs/spec-pack/product/tech-stack.md` and `docs/spec-pack/orchestrator/decisions.md` win over everything else (Spring Boot 4.1.2, Spring `RestClient` only, `MockRestServiceServer` only for HTTP contract tests, no WireMock, no MockServer, Jackson 3, no custom ObjectMapper).
- `agent-os/standards/architecture.md`, a pointer to `docs/spec-pack/product/architecture-standard.md`: the layers and dependency rules (section 2: `RestClient` only in `acl`, `acl` never accesses `domain`), naming (section 3: `acl` classes end with `AppServiceImpl` or `Properties`, payloads are private nested records), ports speak JDK types and DTOs with nested port exceptions extending the four use-case exceptions (section 4), and the testing standard (section 5: acl contract tests with `MockRestServiceServer` bound to `RestClient.Builder`, no test calls the real distributor, PostgreSQL via Testcontainers only).
- Skills: bookstore code is written through `.claude/skills/hexagonal-slice` (with `clean-hexagonal-onion`, `ddd-building-blocks`, `layer-testing`). The standard and the spec win over the skills.
- Repo rules from `CLAUDE.md`: referee `./mvnw clean verify` green, budget 60 s; never skip, disable, delete or weaken a test or an ArchUnit rule; never add `ignoreDependency`; never `--no-verify`; never force-push; plain English without em dashes; product files ASCII only; never set, read or write `ANTHROPIC_API_KEY`; product code never references `docs/spec-pack`, `agent-os`, `.claude` or `CLAUDE.md`.
