See also [[qa-directive-traps]] and [[review-calibration]].

1. **commit-tree is deterministic.** Equal tree, parents, message, author and committer identity and dates give the same SHA. A hermetic test that pins GIT_*_DATE lets an "always create a new commit" mutant pass every idempotency assertion. Demand different committer dates between the two runs (or unpinned dates plus a 1 s sleep), a must-fail probe "always commit-tree", a control with the date step removed (the mutant must then survive), and a witness that a local branch with the same tree but a parent is not reused.
2. **Push flags survive sequential tests.** Dropping `--atomic` or replacing leases by `--force` passes any test without a concurrent writer. Witnesses: an `update` hook in the bare remote rejecting the tag (atomic: main stays); a PATH shim `git` that moves the remote ref before forwarding `push` (lease: `stale info`, nothing moved), also recording the push argv. A no-op rerun cannot test a lease: test it on a run that really moves the ref. A broken origin URL must not fail the default (no `--push`) mode; `--remote` honoured with a broken origin plus a good named remote; an empty `--remote ''` is a usage error.
3. **Reuse precedence.** When a script can reuse a baseline from the remote or a local branch, ask for a witness where both are valid baselines with different SHAs (second machine: default mode first, then `--push`), or a swapped order that force-moves the public ref survives. One case is not enough: a "newer (or older) committer date wins" variant survives a single local baseline on one side of the remote's date. Ask for two cases, dated before and after the remote, each with setup checks (distinct commit, `%ct` order) proven live by a flipped-date variant, and name the tag-first and "local main equals local tag" variants as must-kill.
4. **Path matching.** Look-alike witnesses for every listed path (`.claude-foo/`, `CLAUDE.md.example`, `docs/specs-notes.md`, nested `x/specs/y`, `docs/spec-pack-old/`) kill prefix-grep mutants; a guard run from a subdirectory kills a missing cd to the top level. Root-only lists miss nested agent files: price it at Gate 1. Over-match mutants differ per git command: `ls-files`/`rm` pathspecs glob (`"$p*"` takes `guidelines.md`), but `git ls-tree -- "$p*"` is literal, so use a string-prefix (`awk 'index($0,p)==1'`) and a substring (`grep -F`) mutant there; a strict `"$p*"` misses a `.yaml` twin of a `.yml` path (ask for `x.yml.disabled` plus a stem mutant).
5. **Refusals need each shape.** Clean-tree: tracked, staged, untracked non-ignored (an ignored file must not refuse), and untracked under `status.showUntrackedFiles=no` (kills a dropped `--untracked-files=normal`). Branch: detached HEAD at the branch's commit and a `name-x` branch. Remote equality: ahead, behind and diverged (kills an `is-ancestor` check). Every refusal asserts refs unchanged.
6. **Recipe gap before the gate.** Nothing is committed before the gate, so a clone of the task branch lacks the script under test. Recipe: clone into SP, rename the branch, `cp -p` the uncommitted files, commit in the scratch clone, bare repo in SP as origin. Git writes only inside scratch repos, never the project repo or its worktrees (a default-mode run moves the shared repo's local refs). Fresh-clone builds install node and npm: give them their own budget.
7. **Script-interpreter trap.** `/bin/bash test.sh` proves nothing about bash 3.2 when the test calls `bash "$SCRIPT"` (resolves bash from PATH, Homebrew 5 on this Mac). Require `"$BASH" "$SCRIPT"` and, as evidence, a logging PATH shim for bash with 0 calls plus bash-4 mutants (`${x,,}`, empty `"${a[@]}"` under `set -u`) that die. shellcheck passes both mutants; a summary line printing `$BASH` names the test's interpreter, not the script's. CI on ubuntu is bash 5 only: 3.2 stays a manual check.
8. **Tooling.** Linux run in `ubuntu:24.04` plus apt git. Hermetic proof: a hostile HOME .gitconfig (gpgSign with a failing program, other default branch, failing hooksPath, useConfigOnly, showUntrackedFiles no) must keep the test green. shellcheck and actionlint are not installed locally: docker images, digests recorded; actionlint on an existing workflow may carry base findings, so phrase the criterion as "adds no finding".
9. **Safety record and the live reuse harness (final brief).** Record local refs with `git for-each-ref <refs>` and the remote with `git ls-remote origin <refs>`, start and end (`git rev-parse --verify -q a b` with two refs exits 1 even when one exists). A reuse-precedence harness needs a second clone with no local main AND no origin/main (`git clone --single-branch --branch factory <bare>`); equal SHAs then mean the same commit-tree second, so wait and redo. Its control is the swapped-order script copy against a separate bare remote, which must force-move. A scratch clone of the project worktree has origin = the project path: `remote set-url` to the SP bare repo and print `git remote -v` before any `--push`.
