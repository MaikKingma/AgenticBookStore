Siblings: [[qa-test-data-falsifiers]], [[qa-input-format-falsifiers]]. Survivor judging: [[review-survivor-rules]].

- **Pass-through** (an exception's `details` into a ProblemDetail, an id, a code) needs one test input differing from the default constant, even when the spec only produces the empty value (a handler hard-coding `List.of()` survives); per handler for `code` and `title` too. A String pass-through also survives an inserted `strip()`/`trim()` when no valid test value has edge whitespace, and where payload validation and domain rule treat whitespace differently (`@NotBlank` vs a length-only rule) that insertion makes a "never reached over HTTP" rejection reachable: list one valid edge-whitespace value (`" ab"`) per String pass-through. Write "one case per pass-through with a non-default value, asserted as a literal" into every adapter task.
  - Figures production never varies (reserved always 0, default level 3, quantity 10, a signal never true before the first event) let a hard-coded default survive at every layer (event, DTO, query, view): non-default value per layer, and boundary rows at limit - 1, limit, limit + 1 on a non-default limit for every copy of a threshold. Count copies per comparison site, not per layer (`lowStock()` and the `receive` reset both compared `reorderLevel`): "enumerate every comparison site against the limit in the diff; one default-literal probe per site".
  - A single production value (currency `EUR`, status `PLACED`) is a natural default: non-validating layers need another value in their tests; a layer handing it into a validating factory needs a witness the factory REJECTS, asserted as the exception. Make C0-18 ask per field "plain pass-through or hand-off into a validator" (missing inventory = lens 1 finding). Flow translator branches HTTP cannot reach are reachable through a mocked port returning a corrupt stored DTO: one case per caught type.
  - A choice between two values (override or recommended, given or default) is a relation: two values per field let "keep the higher", "zero means absent" and "use only when different" survive. List data below, equal to and above the counterpart, the zero value and both range ends (equal needs a counterpart in another currency to be visible).
- **State-dependent rules:** a "state unchanged" clause needs a success case starting from each state value (signal false and true); tests starting only from false let an inserted reset pass. "Receive never registers an event" must end low and unsignalled; "restore registers nothing" must restore a low, unsignalled item. Name the state, not just the method. "Every X clears/does Y" next to an unrelated comparison in the same method: a witness strictly inside each region the comparison splits, not only its boundary (a test ending exactly at the level leaves the `>=` guard mutant alive).
- **A rule reporting one element of a list** (the duplicated book, the first unknown book) needs a witness where the element is neither first nor last: A, B, A cannot tell the rule's choice from `get(0)`; B, A, C, A kills `get(0)`; A, C, A, B kills `get(size - 1)`. **"Every rejection asserts no event"** cannot be checked for a throwing factory (no instance survives): write it only for behaviour methods; for factories give it to the publishing layer (flow test, `verifyNoInteractions(events)`).
- **Output-length cap** (`text.length() >= 4000`) is a comparison site: grow the fixture one character at a time to exactly cap and cap - 1 (oracle via the same mapper, [[review-survivor-rules]] rule 5). Annotation-declared requiredness (Spring AI `@McpToolParam`) is readable from `inputSchema().get("required")`: a falsifier, never inspection. A result cap a flow only hands to the port is pinned by the mocked flow test as an argument only; order and cut-off need an IT in two phases: exactly LIMIT rows, then one row sorting FIRST inserted last (kills LIMIT+1, no limit, an insertion-order cut).
- **JSON "key present with null"** (always-serialised optional component): `jsonPath(..).doesNotExist()` passes for absent AND null, `exists()` fails for null: ask for `hasKey`, the key count or a parsed map, plus a `@JsonInclude(NON_NULL)` must-fail probe.
- **"Exact equality" with an expected identifier:** derive the witness set from the operator family, both sides and both receiver orders: leading pad, trailing pad, extension at front, extension at end, proper prefix, proper suffix, plus null. Mutants: `a.op(b)` and `b.op(a)` for op in startsWith/endsWith/contains and strip/stripLeading/stripTrailing (growing the list only by the survivors just seen cost three rounds). A reversed `expected.endsWith(answer)` also accepts the empty string; case-folding mutants are equivalent for digits only. `String.lines()` skips U+2028/U+2029/U+0085: split log lines with `\R`.
