When a spec's acceptance criteria are graded by a checker the team writes itself (structure, coverage, hygiene, contrast), the checker is production code AND the oracle for every later task. Tier the checker tasks critical.

1. **Input probes are not enough.** "An em dash in index makes check fail" proves wiring, not the rule's edges. Add mutation probes on the checker source (rule returns no errors, comparator ignores order, count guard removed, whole-file instead of section-scoped search) that `node --test` must kill. Prove test discovery: a throwaway failing test in the discovery pattern must turn `npm run check` red (catches `;` chaining and zero-test globs). That is not vacuity (`node --test` exits 0 with `tests 0`): put a criterion on the harness task that check fails on zero executed tests. Lockfiles hold third-party names (`postcss-lab-function`), so a word ban must exempt the top-level lockfile by exact path.
2. **Freeze the oracle.** Content tasks hash every checker file against the last gated baseline (a hash chain), not only a fileScope rule. A later fix cycle makes old hash files stale: rebase on `git show <spec-base>:<f>`. A dropped feature may name an artefact the site never had: grep the checker for a pin and tell computed counts from fixture expectations. A pack-derived allow-list inherits pack text a decision left stale: pin it after the freeze.
3. **Coverage-manifest gaming.** Witnesses: a snippet only inside `{/* */}` or `<!-- -->` must not count; a command only in prose inline code must not count when `kind: command`; a snippet present but in another section must fail; a pack line plus an appended command must fail (whole-line, not `includes`). Guard silent exclusion with an independent literal sweep (every code span and fenced line of the source ranges, diffed against manifest plus manual rows). Snippets shorter than 8 chars match anything. A source-text manifest forces Markdown-exact wording (a link, emphasis or backticks inside a snippet break it): hand implementers the forced forms at the freeze checkpoint. A rendered cross-check must delete whitespace, backticks and `|` on both sides (code lines are `.token-line` spans with `<br>`; tables render no pipe). Facilitator-only ranges can overlap required lines: absence greps name facilitator-only phrases. The literal sweep grows with each source edit (one `command` entry holding a whole block covers its lines); exclusions only with a named pin. A deny term added in task N for text a later task removes turns N red: check every new ban against the remaining tasks' text.
4. **Plan-parser witnesses.** Reword only the continuation line of a wrapped source bullet or Goal (kills first-line parsing); drop backticks (kills markup-stripping normalisation); a heading with two parentheticals needs the last one; an in-section `(8 min)` must not be accepted as the level time; the source may quote the anchor phrase elsewhere (a table cell), so a count guard needs a sixth-block probe. H1 and heading rules skip fenced code (bash `# comment` lines are not headings).
5. **Hex colour rules** hit Markdown anchors: `#add-book-reviews` matches `#[0-9a-f]{3}\b` because `-` is a word boundary. Witnesses: `#add-...`, `#bad`, `#cafe`, `{#deadbeef}`. "Colour value" also covers CSS named colours.
6. **Contrast checkers**: recompute every ratio independently; `#767676`/`#777777` on white straddle 4.5; a saturated blue pair catches swapped R/B coefficients; a `var()` chain two deep; dark values falling back to `:root`. Hover states are invisible to axe: hover in Playwright.
7. **Font-loading evidence**: `document.fonts.check()` is true when no face matches (vacuous). Use `document.fonts.load('<w> 16px Family')` then FontFace `status === 'loaded'`, with a negative control (one woff2 deleted in a build copy shows `error`). Unused weights stay `unloaded`.
8. **"Types used" criteria drift.** A rule keyed to what pages use today (admonition types) goes stale when a later task adds one: rewrite to a closed set at strategy time.
9. **Generated folders before their ignore rule.** If task N creates a build folder and the ignore line arrives later, `git add` can sweep it in. Check every folder a task generates with `git check-ignore -v` AT that task; move the line forward if needed.
10. **Docusaurus link checks**: the hash-router build skips SSG and link checks (exit 0 on broken links), so only the browser build is evidence. External links are never checked: inventory them at strategy time; refs a later publish creates get a deploy-gate check, every other URL one request in qa-final.
11. **Docusaurus markup traps**: `{#id}` heading ids do not compile under `future.v4` (use `{/* #id */}`); `- [ ]` task lists render bare disabled checkboxes that fail axe `label` (critical). Say whether "axe" means color-contrast only or the full ruleset, and give every framework violation an owning task (a local rehype plugin sits in the config, outside content and checker scopes). Line-level H1 rules miss JSX `<h1>` and H1s nested in a blockquote or list: pair with a rendered `h1` count per page.
12. **Rehype label plugins and built-HTML guards**: a text walk over `element` nodes drops inline MDX JSX text (`<kbd>`); name the witness or judge reachability through other frozen rules. A built-HTML guard passes vacuously with zero matches and a wrong default dir; when earlier CLI tests are pinned an in-checker floor breaks them, so require a quoted exact tail line (`N html files, M checkboxes`) in every later verifier. Rules on one default-dir switch collide: settle the design before the later task.
13. **Regex scanners of MDX**: each fresh-probe round finds a new construct where scanner and MDX disagree about code, comments or tags. Neither a false span NOR a missed span is safe (blanked text, or a literal `</TabItem>` or `{/*` handed to the tag reader: fail-open). "End the paragraph early" is NOT fail-closed. CommonMark continues a paragraph at an ordered marker other than 1, an empty item, a `<tag>` or `{expr}` followed by text, a `|` line without a delimiter row, `  >` in a list item. Cheap nets: an orphan closing tag and an unclosed or nested comment opener never build, so report them. For a rule whose truth is the rendered page, check the build in CI (`check:built`) at strategy time instead of hardening the source model. Pair source coverage with a rendered textContent cross-check in content verifiers. Trace every consumer before calling an over-approximation fail-closed. Swapping in the MDX parser breaks a "dependency free" rule and a key-set test: a plan decision.
14. **Frozen self-tests must not read the content tree**: "the real guide passes" tests that read live `docs/` freeze the content with the checker. Before the freeze baseline, grep checker tests for reads of the content dir and move them to a committed byte-equal snapshot. A later flag-removal task (marker ban) collides with the snapshot: make it an opt-in the CLI sets on its default root, scoped to `<root>/docs`.
15. **Semantic source reviews of content pages**: verifiers search only the main source file and flag sourced clauses as embellishments. Direct a whole-pack search first; a usage instruction derived from a cited mechanism is faithful, a tool-behaviour claim never is. Facilitator-only ranges overlap participant facts: bar facilitator-only content, accept a fact a participant line repeats; a range that is one page's designated source with named exclusions is ruled by its exclusion list. Print: `page.pdf` is margin 0, a dialog about 10 mm; check both, with a pre-trim control build. A trim-for-fit card names what may not drop; its oracle is a word-sequence diff vs the previous bytes. A literal ban needs replacement wording that keeps the referent.
16. **axe on `file://`**: axe-core's CSSOM preload XHR fails, logging `Couldn't load preload assets:` plus a CORS error and `net::ERR_FAILED`, one triple per run. Accept it only in the axe phase with phase-tagged one-per-run counts, never in Firefox, Pages or dev mode; full-axe evidence includes the http build.
17. **Shape rules are not count rules**: a rule validating a Checkpoint's shape passes a page with none. Put per-page block counts into the content verifiers' rendered assertions with one must-fail retitle mutant. Before sending an anchor or markup form in a directive, read the skeleton and the checker constant that pins it. Run any author alphabet over the grammar's pinned strings (a colon in exact track labels); exempt exact strings, never a character. A count of 0 is valid when every candidate is barred by the grammar; pin it by add-one.
18. **Framework-derived and repo-relative text**: Docusaurus builds `<meta name="description">` from the first paragraph and dropped text between two colons of a pinned Goal line; no source rule sees it. Grep built descriptions of every page at strategy time; the fix is a quoted `description:` frontmatter. Manifest command entries are substring matches (`which jdtls-lsp` passes): ask for whole-line command equality. A class a pack prompt names may be missing only because the spec branch lags the integration branch: check `origin/factory` first.
19. **Derived prompts for pack scenarios**: when the pack gives GIVEN/WHEN/THEN but no prompt words, a fenced prompt is a valid forced form only if it restates the WHEN clause and adds no output, path, tool or flag, and the Expected line is the THEN clause verbatim. A GIVEN no page provides is stated as a precondition, never an invented setup step. Check deny-rule scenarios against the tool the rule names (a `Read()` deny does not cover a Bash read): a rehearsal item, not a page finding.
