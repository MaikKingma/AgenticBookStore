Rule: build your own token inventory before reading the implementer's table, then diff the two; prove each zero-token claim with your own script and a negative control.
**Why:** a table that says "every token" is only as complete as its author's list; a first round missed two tokens that sit in prose, not backticks ("PostgreSQL in Docker", "React storefront").
**How to apply:**
- Inventory script (`python3 -I`): backtick spans, plain `docs/` paths and glob lines of each staged file with file:line, auto-resolved with `git ls-tree` and `git grep` on the sandbox; then read the staged text once more for unquoted facts (versions, ports, libraries, stack words), JSON keys, bold UI terms, URLs. Control: an in-memory copy with two misspelled tokens must report `grep-files 0` or `ABSENT`. Also grep the WHOLE pack for other spellings of a command (a second spelling elsewhere is a product finding).
- Glob test: your own (regex translator plus git `:(glob)` pathspec, frontmatter read by the script). Besides in-script widened globs, a FILE-level control: `git clone` the sandbox to scratch, edit one rule's `paths`, expect exit 1.
- Row check: join the pack prompt lines (strip `> `, one space), compare with the checklist literal and the guide line; copy the pack scenario block by line range and compare byte for byte; each GIVEN/WHEN/THEN fragment must appear in the checklist table. A typo control that prints which index it mutates (a control on a line without the replaced word proves nothing).
- Quote-lookup pass (catches altered literal quotes): per LINE take every double-quoted string of 15+ chars, normalise whitespace, look it up in the union of pack, plan, guide pages (`git show <branch>:<path>` in the script), fetched docs (strip tags, `html.unescape`, also compare with whitespace removed; elided quotes: verify both ends) and staged files, leaving the files under test OUT of the union. Control: a mutated quote must be NOT FOUND. Whole-block byte compares missed a one-word insertion ("and") inside a prose cell.
- Cheap claim audit: `ls` the implementer's scratchpad folder (a leftover script contradicted "no transcript exists"); `diff` evidence files against raw copies; non-ASCII `rg -c "[^\x00-\x7F]"` (rg may be missing inside scripts: python bytes) with a printf-built control; home-prefix, owner-handle and scratchpad-prefix grep with a positive control. A rework that "replaces an evidence file by a fresh run" is where hygiene regresses (raw output prints absolute scratchpad paths): re-run these greps over the whole records folder every round.
- Re-verification: carry old runs over by hash (staged files vs the old sandbox via a script with a DIFF control; untouched evidence by `shasum -a 256`). Base ref moved: `git diff --stat old new -- . ":(exclude)<stripped dir>"` empty plus the same diff on the stripped file as positive control. "Insertion only" on an evidence file: delete the claimed ranges from a copy of the new file and `cmp` with r0 (`od -c` on the first differing byte); a prefix-hash search over every prefix length proves a pure append; non-append insertions need a token-level greedy subsequence (`\w+|\s+|[^\w\s]`, plus a changed-number control: char-level difflib can hide one); editorconfig trimming hides a stripped trailing space.
- Rehearsal-row dry run (git rows): clone with the row's OWN recipe (`git clone --branch <real branch>`; a stand-in on `main` made a literal `git status -sb` line wrong), run every undo sequence and then the NEXT variant (`reset --hard` after a commit drops a staged-only change: use `--soft`), check what the undo leaves behind (`remote set-url` to a scratch bare survives `clean -fdx`). Literal expected output (`Permission denied`) depends on the shell (zsh lowercases): hedged "should" plus "quote what you see" passes, a literal match does not. Run a row's command verbatim after any rework (plain `git status --short` folds a new folder to one line, 10 vs 29).
- False-universal search over a cheat sheet or skill reference ("X has/is/does Y", "every ..."): enumerate EVERY generic sentence yourself, count instances on the base ref with a python script (strip comments AND string literals before name matching), judge by unit (method, package, file); a trace row to the standard does not make a descriptive sentence true; diff the author's claim list against yours. Re-audit after a "make it prescriptive" rework: census per package from imports AND fully qualified names, every money-like field with its type, the author's per-unit table with your own unit splitter (dropped-unit control), low-overlap citations printed line by line, every negative `git grep` with a positive control on the same pathspec.
