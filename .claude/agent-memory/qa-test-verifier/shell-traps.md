Rule: quote every glob-bearing argument; the Bash tool runs zsh, which fails on unmatched globs before the command runs (looks like an empty, passing result).
**How to apply:**
- `"--include=*.java"`, `find ... \( -name a -o -name b \)`; double-quote absolute paths (repo paths contain spaces); quote URLs with `?` in curl. `echo ==== label` fails in zsh (`=cmd` expansion) and aborts the rest of that line: quote separators and check every grep in a chained line printed.
- The Bash tool's cwd is the main checkout, not the worktree: relative `rg`/`shasum -c`/`git` paths read the wrong tree, and a path built without the `.claude/worktrees/<id>` segment still exists (a `printf >` succeeds silently outside the worktree).
- `./mvnw ... -l <scratch>/referee.log` keeps console out of context; grep the log for the reactor summary, `Tests run:`, `Creating container for image` (also matches ryuk: count `postgres:18.6`) and `Started [A-Za-z.$]+ in `. Summary greps over `npm run check` logs: anchor `^ok   (coverage|content)|ℹ (tests|pass|fail) `.
- `git grep -E` does not understand `\s` or `\b`: a readiness grep (`.only`, skip, Disabled) with them is silently vacuous. Use `[[:space:]]`, `(test|it|describe)\.only\(` (plain `\.only\(` hits `author.only()`), and prove it bites with `git -C <scratch> grep --no-index -n -E P <control-file>`.
- `grep` is ugrep: a missing path gives exit 2 with a warning while other paths still print; term-absence greps without `-w` hit substrings (`top-?p` matches "stopping"); a raw NUL in a Maven log prints `Binary file ... matches`: use `grep -a`. In the Bash tool a `grep`/`rg` with no match shows "completed with no output", not exit 1 (`git grep`, `lsof`, `cmp` do show it): give every empty grep a positive control.
- Inside `bash script.sh`, `grep` is BSD grep (`-P` prints a usage error, the count comes out empty, which looks like a clean ASCII check), and `rg` is a zsh function, not a binary (exit 127). Run non-ASCII checks (`rg -c "[^\x00-\x7F]"` with a printf-built control) directly, or define `rg() { ( exec -a rg "${CLAUDE_CODE_EXECPATH:-$HOME/.local/bin/claude}" "$@" ); }` in the script and print `rg --version`. In rg `-h` is help and `-E` is encoding (exit 2, looks like no output): use `rg -ni "a|b"`.
- In a script `echo "a $(cmd1) b $([ $? -eq 0 ] ...)"` reads cmd1's `$?`: capture `rc=$?` on its own line. Never name a script variable `LANG` or `LC_*` (already exported: every later `node` exits 139, `perl` warns, probes show `exit=139`). macOS `/bin/bash` is 3.2: no `declare -A` or `${!arr[@]}`. A script exporting `PATH=<pinned node>:/usr/bin:/bin` loses `lsof` (in /usr/sbin): "command not found" looks like "port free".
- The Edit tool trims trailing whitespace in `old_string`/`new_string` (a probe ending in `, ` restores without the space; "String to replace not found"): anchor on text not ending in a space and compare hashes after the last restore. The Write tool turns U+2003 into a plain space (and trims a file holding only U+2003): build non-ASCII controls with `printf 'a\xe2\x80\x83b\n' > <file>` and check with `od -An -tx1`; the em dash survives; a backslash-u escape typed into Write/Edit lands as the real character: describe escapes in words and `rg -c` every written file.
- Worktree-isolation guard refusals ("cannot be shown not to run git" / "too complex"): `bash <script> git -C <repo> ...` (git in argv), bare `bash --version`, `bash ~/.claude/scripts/with-budget.sh 900 bash <script>` typed directly (put the budget call in a wrapper script), `$HOME`/`$VAR` arguments, `echo`/`git` after `;`, `&&`, `$(...)`, `| tee`, backslash-escaped spaces (double quotes work). Direct `git -C <scratch clone> ...` and `bash <abs script>` are allowed; one plain `git` per call; `git grep --no-index` refuses a path outside the repo (use `grep -nP` with a printf control).
- Mutant generators: `grep -cF -- "$OLD"` with a newline in `$OLD` is two patterns (the empty one matches every line): count with `OLD=... perl -0ne '$c = () = /\Q$ENV{OLD}\E/g; print $c'` and replace with `perl -0pe 's/\Q$ENV{OLD}\E/$ENV{NEW}/'`. Byte copies named by basename collide (`rules/content.mjs` and `lib/content.mjs`: the runner "restored" the wrong bytes, every later mutant read the wrong file): name copies by path-derived names and abort at start when `sha(orig) !== sha(file)`.
- Hash baselines are `shasum -a 256` (plain `shasum` is sha1); a snapshot mixing porcelain and hash lines: `grep " <path>$"` also matches the status line: filter `^[0-9a-f]{64}  ` first.
- macOS `mktemp -d` without a template ignores TMPDIR: use `mktemp -d "${TMPDIR:-/tmp}/x.XXXXXX"` (for a README run with bare `mktemp -d`, list and delete its folders and report it). The JVM ignores TMPDIR too: `JAVA_TOOL_OPTIONS=-Djava.io.tmpdir=<scratch>` for `./mvnw` (forks inherit it).
- Waiting for a background batch: a foreground `bash <wait script>` with a `sleep 10` loop (about 3 minutes per call); bare `sleep` is blocked and a Monitor alone ends nothing for a subagent. A `run_in_background` command that itself backgrounds `java -jar &` exits at once and the jars keep running: stop by PID file, then `lsof` the ports.
