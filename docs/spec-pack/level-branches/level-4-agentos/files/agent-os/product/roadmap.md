# Product Roadmap

## Phase 1: MVP

- Catalogue: books, ISBN, money, search
- Inventory: stock levels, receiving stock, low-stock event
- Orders: place and ship orders, stock reservation
- Distributor service: REST API and our own MCP server
- Distributor ACL: import titles, request restock
- Restock process adapter
- Bookstore assistant with Spring AI
- Storefront: React and Vite UI served by the bookstore

## Phase 2: Post-Launch

- Assistant chat widget with streamed answers (bookstore, frontend). Optional; not part of the first release.
